# Badger's complete tool allowlist. One exact tool name per line.
# Anything not listed here is blocked — including tools that do not exist yet.
#
# This is an allowlist, not a blocklist, on purpose. Matching on verbs like
# "send" or "delete" fails open on neutrally-named mutators: gmail__modify_labels,
# drive__update_permissions, or a future github__merge_pull_request would all
# sail through a verb filter while changing state. Listing exact names fails
# closed instead: a tool we have not vetted cannot run.
#
# MCP tools are namespaced <server>__<tool>, where <server> is the key in
# agent.yaml's mcp_servers map. Renaming a server there silently invalidates
# every entry below, so the two must be changed together.

# --- builtins -------------------------------------------------------------
# Badger reads and reports. It does not need cli, write, edit, capture_photo
# or skill_learner, so they are absent and therefore blocked.
read
memory
