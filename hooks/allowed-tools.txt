# Badger's complete tool allowlist. One exact tool name per line.
# Anything not listed here is blocked — including tools that do not exist yet.
#
# This is an allowlist, not a blocklist, on purpose. Matching on verbs like
# "send" or "delete" fails open on neutrally-named mutators: gmail__modify_labels,
# drive__update_permissions, or a future github__merge_pull_request would all
# sail through a verb filter while changing state. Listing exact names fails
# closed instead: a tool we have not vetted cannot run.
#
# MCP tools are namespaced <server>__<tool>, where <server> is the key in
# agent.yaml's mcp_servers map. Renaming a server there silently invalidates
# every entry below, so the two must be changed together.

# --- builtins -------------------------------------------------------------
# Badger reads and reports. It does not need cli, write, edit, capture_photo
# or skill_learner, so they are absent and therefore blocked.
read
memory

#   node scripts/composio-session.mjs status
#
# Composio's GitHub toolkit exposes 823 tools — the whole GitHub REST API,
# including GITHUB_BLOCK_A_USER and GITHUB_ADD_A_REPOSITORY_COLLABORATOR.
# The 12 below are what a session with the DIRECT_TOOLS preset registers.
#
# Two things this file's allow-by-name rule now has hard evidence for:
#   1. GITHUB_LIST_REPOSITORY_SECRETS and GITHUB_GET_A_REPOSITORY_SECRET are
#      read-shaped tools that read credentials. A "LIST/GET is safe" heuristic
#      would hand Badger repo secrets. Naming each tool is not pedantry.
#   2. A default (non-DIRECT_TOOLS) session registers COMPOSIO_MULTI_EXECUTE_TOOL
#      and COMPOSIO_REMOTE_BASH_TOOL — one generic name that runs anything.
#      Name-based gating cannot see through that, so this file would pass every
#      write while looking green. The preset is load-bearing, not a tidy-up.
#
# Namespacing is NOT settled: these are Composio's own slugs. How they appear
# to gitagent depends on the wiring (session MCP endpoint vs SDK), which is
# still open. Re-run the probe after wiring and fix the prefixes here.
